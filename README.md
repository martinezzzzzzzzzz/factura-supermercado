# 🛒 Factura de Supermercado
 
# Este proyecto es una aplicación de consola en Python que simula la generación de una factura de supermercado. Los usuarios pueden seleccionar productos predefinidos y obtener el total de su compra.
 
## 📌 Características
# - Lista de productos predefinidos con precios.
# - Cálculo automático del total de la compra.
# - Uso de entornos virtuales y gestión de dependencias.
# - Integración con GitHub para trabajo colaborativo.
 
## 🛠 Instalación y Configuración
 
### 1️⃣ Clonar el repositorio
# Ejecuta el siguiente comando en la terminal:
# git clone https://github.com/martinezzzzzzzzzz/factura-supermercado.git

 
### 2️⃣ Crear y activar un entorno virtual
# En Windows:
# python -m venv .venv
# .venv\Scripts\activate
# En macOS/Linux:
# python -m venv .venv
# source .venv/bin/activate
 
### 3️⃣ Instalar las dependencias
# pip install -r requirements.txt
 
## 🚀 Guía de Uso
# Ejecuta el script principal del proyecto:
# python factura.py
# Selecciona los productos ingresando sus números.
 
# El sistema calculará automáticamente el total de la compra.
 
# Confirma la compra y revisa el resumen de la factura.
